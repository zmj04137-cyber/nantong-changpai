# 南通長牌 · 笃子胡

暗红丝绒上的地方牌局。React + TypeScript + Vite 纯静态单机网页；一名真人、三名本地电脑，四人轮换、三人行牌、一人定醒。无数据库、业务API、充值、提现和联网房间。

## 开发

Node.js 22+，pnpm 11。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

构建产物在 `dist/`，支持任何静态 HTTPS 托管。`base: './'`，页面状态保存在浏览器内存和localStorage，不使用需重写的路由；因此部署在子目录后刷新也能恢复首页，再选择继续游戏。

## 模块

- `src/engine/cards.ts`：120张实体牌，每张唯一ID。
- `src/engine/config.ts`：独立双将规则配置、产品补充约定。
- `src/engine/winning.ts`：全部七组加一对的合法拆分。
- `src/engine/scoring.ts`：胡型、分档、附加、倍数与未胡组合计分。
- `src/engine/game.ts`：四人轮换、声明、摸打响应、杠后补牌与差额结算。
- `src/engine/ai.ts`：仅接收自己的手牌、亮牌和公开信息，不接收对手手牌或牌堆。
- `src/storage.ts`：带版本的牌局和设置存储，损坏存档会忽略。
- `tests/engine.test.ts`：规则测试与100局完整电脑模拟。

## 规则口径

采用[唐人游2017双将分表](https://nantongchangpai.uc55.com/Rule/Detail/201711_000137.html)，四老将为九条、红花、白花、千字；不混入单将147/258/369或全部头尾常将算法。参考[基础入门](https://nantongchangpai.uc55.com/Rule/Detail/201711_000165.html)的四人轮换和三家差额结算结构，但不采用其中不同的暗刻分表。

资料未完整覆盖的响应顺序、补牌结构、进整顺序、流局支付和双同指示叫牌，已在游戏“玩法说明 → 产品约定”和config.ts中公开。双同指示的两实体叫牌按将头锁定，不算额外一组、不补牌，计64或128胡。不能冒充统一地方规则。

首版不启用：报听、喜儿、穷狠、一胡头儿、清儿带把子、后摸、地胡、天听、海底捞月。文钱三组依所选资料允许另计暗刻，这是计分复用，不复制实体牌。

## 素材

三张背景/标题为用户提供的红丝绒、帷幕与透明手写标题。27张基础牌面使用本次对话交付的AI重绘素材并压缩为本地WebP，识牌以叠加的清晰花色数字为准；红花、白花、千字用文字牌面。未虚构人物出处。不加载Google Fonts、外部图片或运行时CDN脚本。背景音乐采用用户提供的velvet-piano.wav，首次操作后循环播放；九种轻柔按钮和纸牌音效已预生成本地WAV。音乐与音效独立开关和调音量，无外部请求。

## 发布

`.github/workflows/deploy.yml`：main分支推送后安装、测试、构建、发布到GitHub Pages。仓库Settings → Pages需选GitHub Actions。GitHub Pages适合本纯静态非商业游戏，免费公开仓库可用，已发布站点1GB上限，月流量100GB软限制；以[GitHub官方限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)为准。

`.openai/hosting.json`另提供Sites静态发布配置，使用同一dist，不改业务代码即可迁移。不要将可部署文件或本地预览误称为实际已上线；最终实际网址和访问测试见本次交付说明。

中国大陆电信、联通、移动真实网络均需实测，未经实测只能标注“大陆访问尚未验证”。海外某一网络成功也不代表所有地区可达。用户可用自己网络测试最终网址。无免费平台永久稳定承诺。

## 稳定理牌与对局交互

默认万1—9、条1—9、饼1—9、红花、白花、千字；同牌按唯一ID稳定排列。九条不移位，只标老将。独立hand-order.ts只维护显示ID序列，不修改引擎手牌与亮牌。

起手自动整理；新摸牌独立右置，无定时自动归位。自动开时出牌或整个响应结束后再归位，选牌和拖动中延迟；自动关时新牌留右直到手动理牌。手动理牌与刷新均保留有效选中ID及显示顺序。

对局采用围坐布局：左右对手、底部自己，当前出牌进共享空间，历史弃牌抽屉按归属显示真实牌面；查看时暂停行动且保留回合提示。真人定醒时第三名电脑使用底部座位，真人在边缘观战。

本地测试覆盖26项，其中9项为独立理牌行为，另包含100局完整模拟。浏览器已检查23张起手、选牌取消与确认、合法响应、刷新保留选中牌和844×390嵌入横屏。
